Night Courier is a 2D top-down stealth game: slip through three patrolled districts, stay out of the guards' vision cones, hide behind cover and in the shadows, and reach the exit unseen. Sneak slowly and silently or sprint noisily, throw coins to distract patrols, and earn a ghost bonus for a clean run. Built by an AI agent for make.fun's “Make the best stealth game” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
